# Shah Samiur Rahman — Research Portfolio

A responsive single-page portfolio website built from the information in Shah Samiur Rahman's CV.

## Files

- `index.html` — website structure and content
- `style.css` — responsive styling and theme
- `script.js` — mobile navigation, dark/light mode, and active navigation
- `assets/profile.jpg` — uploaded profile photograph

## How to run

Open `index.html` in a browser.
